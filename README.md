# stupko.ru

Открытая часть — `index.html`. Подробная история — `rod.html` + `rod.enc.json` (AES-256-GCM,
ключ содержимого завёрнут отдельным паролем для каждого человека, PBKDF2 600 000 итераций).
Пароль проверяется и страница расшифровывается в браузере. На сервере — только статика.

Управление доступами (не в этой папке): `python3 ../access/access.py add "Имя" | revoke "Имя" | list | build`.
После правки `rod-stupko.html` — `access.py build`, затем `../site-deploy.sh`.
